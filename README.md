# AetheriaSky Official Portal

Je veux créer le site officiel de mon serveur Minecraft : AetheriaSky.

IMPORTANT :

Je veux un site entièrement personnalisé et original.

NE PAS utiliser un template générique de serveur Minecraft.

NE PAS donner l'impression que le site est un modèle Lovable modifié.

Le site doit avoir sa propre identité visuelle AetheriaSky.

- propre

- nature

- lumière douce

- profondeur
